# SQL Case Study Assignment

Two portfolio-ready SQL projects analysing real business datasets with MySQL.

## Projects

| Project | Dataset | Focus |
|---|---|---|
| [Project 1: E-commerce Sales & Customer Analytics](Project%201%20-%20E-commerce%20Sales%20%26%20Customer%20Analytics/) | Brazilian E-Commerce Public Dataset by Olist | Sales trends, product and seller performance, delivery, customer ratings |
| [Project 2: Customer Segmentation & Revenue Intelligence](Project%202%20-%20Customer%20Segmentation%20%26%20Revenue%20Intelligence/) | Chinook Database (digital music store) | Customer segments, spending, country and genre analysis, revenue trends |

Each project folder has its own README with the business problem, schema, key findings, and setup steps.

## Tools

- MySQL 8.0 or later
- MySQL Workbench
- GitHub

## Getting Started

1. Read the README in the project you want to explore.
2. Set up the dataset in MySQL as described in that README.
3. Run the project's `Project Questions.sql` file.
